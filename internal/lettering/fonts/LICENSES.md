# Lettering fonts

These fonts are embedded for server-side lettering, compositing and export. All are licensed under the SIL Open
Font License 1.1 (full text in each section below); nothing is loaded from the host or the network.

|---|---|---:|---|

| `deva` | NotoSansDevanagari-Black.woff2 | 58,340 | github.com/notofonts/devanagari release NotoSansDevanagari-v2.007, `NotoSansDevanagari/full/ttf/NotoSansDevanagari-Black.ttf` (sha256 cca679f1af8dd81fac8f469519ec66a2d54f1773728388a46c9ec9ef4e22db26); the "full" build also carries Noto Sans Latin, the fallback for Latin letters Comic Neue and Bangers lack (for example Ÿ) |

The four Noto conversions keep every code point the source maps and convert with fontTools 4.68 `subset`
(`flavor=woff2`, `hinting=False`, `notdef_outline=True`, all name records, `DSIG` dropped). The CJK files keep the
layout features lettering uses (`ccmp locl liga calt kern mark mkmk palt halt vert vrt2 vkrn vpal vhal`); the
Devanagari file keeps all features. Hinting is removed because lettering is always converted to outlines.
These are modified versions under OFL section 2; no Reserved Font Name applies to the Noto fonts.
