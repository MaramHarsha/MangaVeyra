## Defects reproduced and corrected

1. **Digests ignored quiet hours.** A daily digest was sent at 07:00 in the
   member's Asia/Tokyo quiet window. It now waits until the window ends without
   consuming that day's delivery. Reproduced on both databases.
2. **An SMTP failure consumed the digest interval.** A server returning SMTP 451
   prevented another attempt for a day. `last_digest_at` is now recorded only
   after delivery succeeds. Reproduced on both databases.
3. **Digests ignored per-event email opt-outs.** Disabling mention emails still
   allowed them into a digest. The query now selects only opted-in kinds before
   applying its item limit. Coverage also puts 101 newer non-email job events in
   front of an eligible review. Reproduced on both databases.
4. **Missing S3 bucket reported ready.** The S3 probe discarded the false result
   from `BucketExists`. Removing the configured bucket left `/readyz` returning
   HTTP 200 with `ready:true`. It now returns 503, keeps `/healthz` at 200, and
   recovers to 200 after the bucket is recreated. Reproduced before the fix and
   verified afterward through the real app on both SQL dialects and the final
   Linux container.
5. **Clock-dependent test.** The existing email test assumed the real UTC clock
   was inside 00:00–23:59. It failed during the excluded minute. Its service clock
   is now fixed explicitly.
6. **Ambiguous reader test selector.** Guided reading has a header control and an
   in-reader control. The mature-reader assertion matched both. It now targets
   the reader header; the publish/read flow passes.
7. **Race in the update download fixture.** A canceled HTTP handler could read a
   function pointer while the next subtest replaced it. The fixture now routes
   each scenario to an immutable handler. Repeated race checks pass.
8. **MCP race-test deadline.** Its full-page generation wait used the same
   60-second deadline with and without instrumentation. The approval test passed
   alone in 266.9 seconds overall, but one job exceeded the bound in the combined
   run. Test build tags now apply the repository's tenfold race allowance;
   ordinary tests keep their original one-minute bound. Production limits are
   unchanged. The complete MCP package passes after this correction (37 passing
   test/subtest results, 578.3 seconds). CI now uses bounded package concurrency
   and a 30-minute package timeout; the workflow YAML was parsed locally.
9. **Maintenance page ignored the visitor's language.** The maintenance gate ran
   before locale resolution, so a Japanese visitor got the G6 page in English.
   The gate now resolves the locale for its holding page.
10. **"Placeholder art" was untranslated.** The built-in image row on the Models
    page skipped the display-name catalogue. It is now translated.
11. **E2 Export was not a real modal with JavaScript.** The dialog renders open
    for no-JavaScript use, so focus never moved in, Tab left it and Escape did
    nothing. Static modals with a close address are now re-opened as modals and
    go to that address on close (local paths only). Dropdown menus gain
    ArrowUp/ArrowDown/Home/End. Checked in Chrome: modal, focus inside, Tab
    trapped after 25 presses, Escape returns to the editor.
12. **Lettering timing tests flaked under load.** Three wall-clock bounds failed
    when the whole suite ran in parallel. They now also scale by a small-layout
    timing taken at that moment; the work counters still bound the algorithm.
    Passes 3/3 with twice as many busy loops as CPU cores.
13. **Security hardening.** Dependency bumps (govulncheck clean), Secure and
    HttpOnly session cookies, Compose and systemd hardening, SECURITY.md,
    ignore rules for keys and backups, and server size-limit tests.

## Limits

Live cloud-provider behavior, actual NVIDIA hardware, full-size model
training/quality, vendor-specific cloud storage behavior and real external
notification delivery are not certified by these local checks. Tiny-model CPU
integration and local S3-compatible storage are verified. Real PDF import requires
`pdftoppm`; it is absent on the host and was verified in the container build.

Existing disabled Soon/stub features remain outside the implemented release:
templates, translation, animation/living panels, EPUB/video export, named history
branching/merge, World integration, the MCP client and plugin directory. A version
string does not make these runtime paths implemented. README/roadmap sections also
retain older pre-alpha/phase wording; no release marketing claim was changed.

Not completed in this pass: a full role-by-route authorization matrix, a
dedicated load/performance run, and a systematic markup-escaping sweep. Existing
permission and escaping tests pass; these broader sweeps remain follow-ups.
